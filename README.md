# MARU Platform — Claude Code 플러그인

Claude Code 에서 MARU 플랫폼으로 빌드를 올리고 테스트 트랙에 릴리스하는 플러그인입니다. MARU 계정으로 로그인해서 씁니다.

## 설치

Claude Code v2.1.231 이상이 필요합니다.

```
/plugin marketplace add code-reach/platform.claude-plugin
/plugin install maru@maru
```

설치한 뒤 한 번 로그인합니다.

```
/mcp  →  maru  →  Authenticate
```

브라우저에서 MARU 계정으로 로그인하고 동의하면 됩니다. 로그인은 대화형 세션에서 해 주세요 — `claude -p` 에서는 로그인 창을 띄울 수 없습니다.

## 할 수 있는 것

- 내 조직 콘텐츠의 새 버전을 만들고, 빌드를 올리고, 테스트 트랙에 릴리스
- 버전 목록과 릴리스 상태 확인

Claude 에게 "새 빌드 올려서 테스트 트랙에 릴리스해 줘" 처럼 말하면 플러그인에 든 절차를 따라 진행합니다. 쓸 수 있는 기능은 계정 권한에 따라 다르고, 권한이 없으면 로그인한 뒤에도 기능이 보이지 않습니다.

## 알아 둘 것

- 테스트 트랙 릴리스도 테스트 트랙을 쓰는 실제 기기에 전달됩니다.
- 정식 릴리스, 공개·숨김 전환, 삭제는 이 플러그인으로 할 수 없습니다. 콘솔에서 해 주세요.
